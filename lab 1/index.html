Миний тухай

Намайг Маргад гэдэг. Би Шинжлэх Ухаан, Технологийн Их Сургуульд мэдээллийн технологийн чиглэлээр суралцдаг. Компьютер, программчлал болон шинэ технологийн талаар суралцах сонирхолтой.

Хичээлээр сурсан зүйлээ лабораторийн ажил дээр туршиж, өөрийн гараар ажилладаг программ, веб хуудас хийхийг зорьдог. Одоогоор HTML, CSS ашиглан веб хуудас бүтээх, Java хэлээр өгөгдлийн бүтэц хэрэгжүүлэх чадвараа хөгжүүлж байна.

Миний хобби, сонирхол

Веб хөгжүүлэлт

Веб хуудасны өнгө, загварыг өөрчилж, бичсэн кодынхоо үр дүнг browser дээр харах сонирхолтой. Өөрийн CV болон бүртгэлийн форм бүтээж дадлага хийж байна.

Компьютер тоглоом

Чөлөөт цагаараа CS2 тоглох дуртай. Мөн компьютерын үзүүлэлт, тоглоомын тохиргоо болон гүйцэтгэлийн талаар сонирхон судалдаг.

Фото зураг

Сонирхолтой агшин, байгаль болон өдөр тутмын дурсамжаа зураг болгон үлдээх дуртай. Зургийн өнгө, зохиомжийг өөрчилж турших сонирхолтой.

Кино үзэх

Чөлөөт цагаараа кино үзэж амардаг. Киноны үйл явдал, дүрүүдийн шийдвэрийг ажиглаж, төрсөн сэтгэгдлээ найзуудтайгаа хуваалцах дуртай.

Миний зорилго

Программчлалын суурь мэдлэгээ бататгаж, өөрөө веб сайт болон жижиг программ бүтээж чаддаг болохыг зорьж байна. Цаашдаа веб хөгжүүлэлт, мэдээллийн аюулгүй байдлын мэдлэгээ гүнзгийрүүлж, бодит төсөл дээр ажиллах хүсэлтэй.
